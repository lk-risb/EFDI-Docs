# NetBird client

## 1. Install

```bash
curl -fsSL https://pkgs.netbird.io/install.sh | sh
```

## 2. Connect

Ask the NetBird admin for both the management URL and a setup key, then join:

```bash
netbird up --management-url <MANAGEMENT-URL> --setup-key <SETUP-KEY>
```

## 3. Verify

```bash
netbird status
```
